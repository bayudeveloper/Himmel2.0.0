Kenapa Himmel API

Sederhana.
Langsung Pakai.

Tidak perlu setup rumit. Cukup kirim HTTP request dan terima response JSON yang konsisten.

01
REST JSON

Semua endpoint mengembalikan JSON terstruktur yang mudah di-parse di bahasa apapun.

02
API Key Auth

Sistem autentikasi berbasis API key untuk endpoint premium. Free key tersedia untuk testing.

03
AI Generation

Text-to-image, AI chat, face swap, video generation dan berbagai model AI lainnya.

04
Multi-Platform

Bisa digunakan dari Python, JavaScript, PHP, atau tools seperti curl dan Postman.

Langsung Integrasikan

Salin kode di bawah ini sesuai bahasa yang kamu pakai. Ganti YOUR_API_KEY dengan API key kamu.

Python
import requests # Base URL API BASE_URL = "https://himmel-api.vercel.app" API_KEY = "YOUR_API_KEY" # Contoh 1 — AI Chat def ai_chat(pertanyaan): res = requests.get( f"{BASE_URL}/ai/chat", params={"q": pertanyaan, "apikey": API_KEY} ) return res.json() # Contoh 2 — Download YouTube MP3 def ytmp3(url): res = requests.get( f"{BASE_URL}/downloader/ytmp3", params={"url": url} ) return res.json() # Contoh 3 — Text to Image def text_to_image(prompt): res = requests.get( f"{BASE_URL}/ai/txt2img", params={"prompt": prompt, "apikey": API_KEY} ) return res.json() # Jalankan result = ai_chat("Halo, apa kabar?") print(result["result"])

JavaScript / Node.js
const BASE_URL = "https://himmel-api.vercel.app"; const API_KEY = "YOUR_API_KEY"; // Contoh 1 — AI Chat async function aiChat(q) { const url = new URL(`${BASE_URL}/ai/chat`); url.searchParams.set("q", q); url.searchParams.set("apikey", API_KEY); const res = await fetch(url); const data = await res.json(); return data; } // Contoh 2 — YouTube MP3 async function ytmp3(videoUrl) { const url = new URL(`${BASE_URL}/downloader/ytmp3`); url.searchParams.set("url", videoUrl); const res = await fetch(url); const data = await res.json(); return data; } // Contoh 3 — Text to Image async function textToImage(prompt) { const url = new URL(`${BASE_URL}/ai/txt2img`); url.searchParams.set("prompt", prompt); url.searchParams.set("apikey", API_KEY); const res = await fetch(url); const data = await res.json(); return data; } // Jalankan aiChat("Siapakah kamu?").then(data => console.log(data.result) );
PHP
<?php define('BASE_URL', 'https://himmel-api.vercel.app'); define('API_KEY', 'YOUR_API_KEY'); // Helper — GET request dengan curl function himmelGet($path, $params = []) { $url = BASE_URL . $path; if (!empty($params)) { $url .= '?' . http_build_query($params); } $ch = curl_init($url); curl_setopt_array($ch, [ CURLOPT_RETURNTRANSFER => true, CURLOPT_TIMEOUT => 30, CURLOPT_SSL_VERIFYPEER => false, ]); $body = curl_exec($ch); curl_close($ch); return json_decode($body, true); } // Contoh 1 — AI Chat $chat = himmelGet('/ai/chat', [ 'q' => 'Halo!', 'apikey' => API_KEY, ]); echo $chat['result']; // Contoh 2 — YouTube MP3 $mp3 = himmelGet('/downloader/ytmp3', [ 'url' => 'https://youtu.be/dQw4w9WgXcQ', ]); echo $mp3['url']; // Contoh 3 — Text to Image $img = himmelGet('/ai/txt2img', [ 'prompt' => 'sunset di tepi pantai', 'apikey' => API_KEY, ]); echo $img['url']; ?>
